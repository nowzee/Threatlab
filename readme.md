
## 🔧 Dépendances Principales

### Backend Python
- **Flask 3.1.1** - Framework web
- **pyotp 2.9.0** - Authentification 2FA
- **qrcode 7.4.2** - Génération QR codes
- **Pillow 11.3.0** - Traitement d'images
- **Werkzeug 3.1.3** - Utilitaires WSGI

### Frontend JavaScript
- **Vue 3.5.18** - Framework frontend
- **TypeScript 5.8.0** - Langage typé
- **Vite 7.0.6** - Build tool
- **Vue Router 4.5.1** - Routage
- **Pinia 3.0.3** - Gestion d'état

## 🔒 Sécurité

- Authentification à deux facteurs obligatoire
- Sessions sécurisées avec tokens secrets
- Validation des endpoints sensibles
- Protection contre les attaques courantes (XSS, injection SQL)
